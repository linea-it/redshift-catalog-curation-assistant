# Scientific Scope

This project does not decide whether a catalog is scientifically valid or ready
for publication.

The curator remains responsible for interpreting survey documentation, choosing
the primary redshift column, deciding how quality flags should be translated,
and approving downstream use.

The tool is responsible for mechanical, reproducible steps:

- reading supported catalog formats;
- summarizing schema, types, candidate science columns, and sample rows;
- applying explicit technical transformations;
- validating configured rules;
- writing auditable outputs.
